## 4. DeepSeek 凭据与在线运行

用户已授权本机保存，不要再让用户在对话里粘贴密钥。本机文件 `~/.local-sensitive/ontopoc/deepseek.env`（0600，仓库外），只读给进程用，不打印、不入库、不进截图和日志。换机器没有该文件就是缺本机配置，请用户补齐。

```bash
( set -a; source ~/.local-sensitive/ontopoc/deepseek.env; set +a
  PYTHONPATH=src:. python scripts/run_public_ontology.py \
    --campaign 21V650000 --campaign 18V576000 --campaign 20V808000 \
    --output "output/public-ontology-$(date +%Y%m%d-%H%M%S).json" )
```

不用 `set -x`；报告路径必须是新文件；请求 temperature 0。运行完把报告复制进 `examples/nhtsa/runs/`，再用 `build_public_review_pack.py --report ... --snapshot ...` 发布；当前两份数据集用到的报告与快照都记在 `landing-page/public/data/index.json`。
