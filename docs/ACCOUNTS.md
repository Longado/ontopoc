# 登录与账号

从 [README](../README.md) 搬来。

服务默认要登录，没有默认账号和默认密码。第一次用先在服务所在的机器上建管理员：

```bash
PYTHONPATH=src python3 -m ontology_poc_generator.accounts create-admin     # 问账号和密码（至少 12 个字符）；忘了密码用同一个工具的 reset-password
PYTHONPATH=src python3 -m ontology_poc_generator.ontology_server --origin http://127.0.0.1:5178   # --origin：页面所在的地址（这里是开发服务器）；可重复
```

管理员在页面“用户”里建其他人：**查看**只能看和提问，**建设**还能上传数据、改定义，**管理员**还能管人。新账号第一次登录必须先改掉管理员给的临时密码。每一次操作都记在登录的人名下，请求里自己写的名字会被忽略。脚本和 MCP 用“我的账号”里创建的令牌（给 MCP 设环境变量 `ONTOPOC_TOKEN`），权限和令牌主人的角色一样，只是在团队工作区里不能确认定义、批准提交的改动、记核对过的数，也不能写、确认或运行“要回答的问题”：这些要本人登录页面来做。令牌可以像它的主人一样读“要回答的问题”清单和结果。

**要回答的问题**：建设者和管理员写团队要回答的问题和每个应该给出什么；两人确认开着时，一个人写的要另一个人确认，上次确认之后改过问题文字或期望的人也不能确认；改了问题的文字或期望就退回“已提出”，改回上次确认的样子就恢复为已确认；只改来源说明不退回。只有不受类型名单、列权限、行规则限制的建设者或管理员能跑（行规则会限制所有没被给到全部行的建设者；管理员不受限制）；受限的建设者既看不到清单也不能跑，会被告知原因。查看者看不到。演示访客不能发起运行。运行有自己的模型调用额度（所有运行合计，任意 24 小时内 300 次），不占个人或令牌每小时能问的问题数。

**两人确认**：有两个以上的人能确认时，一个人提出的定义（含义、对象类型、关系、视图、行为、派生属性、管道）要另一个人确认才生效，提出的人自己不能确认；只有一个人能确认时自动不生效，日志里会标出自己确认自己的那几条。管理员可以在“用户”页关掉。上次确认之后改过一条定义的人（不论登录还是用令牌，改的是名称、说明、另称还是别的）也不能确认它，直到它被一位没改过它的人确认；别人再改也不会把谁的名字去掉。已确认的定义，任何人改了任何一处（包括上次确认它的人），都和令牌的修改一样退回等人确认，读它的东西一起退回；把它改回上次确认的版本，它就恢复为已确认（数据在这期间变了的除外，那时仍要有人再看）。代价：两位建设者都改过同一个定义，就要第三位来确认，或者有人把它改回上次确认的版本；被拦住的人在页面上和拒绝里会看到是谁改过、谁能确认、怎么解开。管道仍按自己的规则：上次确认之后保存过步骤的人不能确认。用令牌做的写入，日志里每一行都写明是哪个令牌。

**值规则和谁看到什么**：值规则是对象类型的一部分，跟着类型由它的确认人一起确认；加、改、删一条规则，类型要重新确认，和改主键一样。违反规则的行数和作为例子列出的主键，按读的人能看到的行来算：受行规则限制的建设者只看到自己那些行的数。某一列不让谁看，那一列上的规则在哪儿都不给他看（对象类型页、待确认、`describe_definitions`）。新数据违反了已确认的规则，类型退回“需再看”；看得到全部数据的建设者和管理员在原因、拒答和状态里看到是哪条规则、多少行；受行规则或列限制的人看到原因的种类，看不到数；只读用户只被告知它在等谁再确认。

**给团队用**：服务本身只听本机，不处理 HTTPS。前面放一个做 HTTPS 的代理，例如 Caddy（完整步骤、备份和权限要点见 [docs/DEPLOY.md](DEPLOY.md)）：

```
ontopoc.example.com {
    reverse_proxy 127.0.0.1:8767
}
```

服务启动时加 `--origin https://ontopoc.example.com`：这个地址才会被接受，登录 cookie 带 Secure，登录次数限制按代理看到的来访地址算。非本机的 http 地址会被拒绝。`workspace.sqlite` 里有密码的哈希和登录记录，文件权限是仅本人可读写，拷贝给别人等于把哈希给了别人。代理要把它看到的来访地址写进 X-Forwarded-For（nginx：`proxy_set_header X-Forwarded-For $remote_addr;`），服务只信这个头的最后一个地址，且只信 `--trusted-proxy` 指定的代理（配了 https 的 `--origin` 时默认是本机）。

**只在自己机器上试**：`--no-auth` 关掉登录，所有请求都当作本机管理员，不要用在共用的机器上。要先设环境变量 `ONTOPOC_DEV=1`；和 `--origin` 一起用会被拒绝，带代理头（X-Forwarded-For 等）的请求也会被拒绝。
