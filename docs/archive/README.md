# Archive

This folder is history: the iteration plans, feature lists, hand-offs, retros and working plans from September and October 2026. They describe what the project was trying at the time, including directions and features it has since dropped. They are not kept up to date, and a command or path in them may no longer work.

For what OntoPoc is now, read [PRODUCT.md](../PRODUCT.md) and the [README](../../README.en.md).

这里是历史记录：2026 年 9 月、10 月的迭代计划、功能清单、交接、复盘和实施计划。它们记的是当时的方向，其中一些方向和功能后来已经放弃，内容不再更新，里面的命令和路径可能已经不能用。现在的产品定义看 [PRODUCT.md](../PRODUCT.md) 和 [README](../../README.md)。
